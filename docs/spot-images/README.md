# Website imagery update

The hidden-discovery catalogue now displays 201 place suggestions, each with a local image. The original 224-row import remains intact. A separate presentation filter excludes 23 scraped headings, navigation labels, named contact snippets and tour advertisements; the exact excluded IDs are in `coverage.json`. These exclusions do not assert that every remaining record is a verified attraction.

22 imported entries have a matched location photograph. The remaining 179 show explicitly labelled category scenery rather than pretending to depict the unverified venue. `content/spot-images.json` records photo metadata, exact-place matches, category matches and exclusions. `scripts/build-spot-images.mjs` regenerates this manifest without modifying the raw import. Every referenced file has a rights record in `content/media.json`.

Eight newly selected Wikimedia Commons photographs cover Ambrai Ghat, Gangaur Ghat, the view from Neemach Mata Temple, Gulab Bagh, Eklingji, Sahasra Bahu temples, Kumbhalgarh Fort and Jaisamand Lake. `imported.json` retains source pages, artists, original URLs, licence names and licence URLs. The new files total about 672 KB. They were proportionally resized to a maximum of 1000px, oriented, stripped of metadata and encoded as WebP. No subjects or source watermarks were edited; adapted photographs retain their source licence and applicable share-alike conditions. Photos can predate current conditions. The contact sheet was visually reviewed; unrelated search candidates (including a bee close-up for Ranakpur and under-construction statue photos) were not published. Search rate limiting prevented further automated Commons searches; no unreviewed search results are hotlinked.

The existing 15 place galleries keep their 27 documented photographs. All ten curated Hidden Udaipur guides now have photo cards and source credits. Accommodation, rental and local-companion entry pages use credited category scenery; the account entry page uses a lake photograph. Forms, navigation, genuine empty social feeds, monogram avatars and private records remain functional UI rather than being populated with fictional people or posts.

Photo frames reserve space, lazy-load local assets and show a useful fallback if loading fails. Photo credits are expandable under each catalogue image. Named Google Maps searches remain independent of the photograph. Category visuals visibly state that a venue photo is not yet confirmed.

Checks: all 27 catalogue photo references return HTTP 200 and have media-rights entries. Search, pagination, noise filtering, exact-vs-category distinction and credits pass browser checks. Hidden discovery, accommodation, rentals, companions and account pages fit 360px, 390x844 and 1440x900 without horizontal overflow or page errors. TypeScript, ESLint and all 156 unit tests pass; the content validator reports zero errors and 44 existing sample/unverified items. Licensed location photos are still needed for the remaining 179 suggestions; category scenery is not a substitute for that verification.
